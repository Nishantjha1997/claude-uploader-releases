Claude Usage Uploader - Developer Setup
=======================================

This folder contains everything needed to install the Claude Usage Uploader service on a new developer's machine.

Instructions:
-------------
1. Copy this entire folder to the developer's computer.
2. Right-click on the "install.ps1" file and select "Run with PowerShell".
   (If it prompts for Administrator permissions, click Yes).
3. The script will copy the necessary files to C:\ClaudeUsageUploader and launch the Setup Wizard in the browser.
4. The developer just needs to enter their name in the browser wizard and click Save. 

The background service will automatically configure itself to run silently in the background on system startup!
