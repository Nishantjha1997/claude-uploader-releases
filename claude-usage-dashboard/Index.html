Overall Value Score Methodology (0–100)

System Standard

The Overall Value Score combines Chat and Code engagement into a unified returns-on-investment metric, indicating how effectively each developer utilizes their flat-fee Claude license (~$20/user/month).

Developer Profile Formulas

  • Has Chat + Code (Hybrid Power User):
    (Chat Score + Code Score) / 2 + 10 Bonus Points (Capped at 100).
  • Chat-Only Active User:
    Value Score equals the calculated Chat Score directly.
  • Code-Only Active User:
    Value Score equals the calculated Code Score directly.

Code Score Components (0–100)

Normalized relative to the team's top performer (percentile distribution):

  • �� Token Volume (40%): Total tokens relative to team high.
  • �� Active Days (30%): Coding active days relative to team high.
  • �� Project Diversity (20%): Distinct repositories worked on.
  • �� Prompt Efficiency (10%): Output tokens relative to total prompt input (evaluates cache utilization).

��️ User Cohort Categorization Rules

User Cohort Automatic Classification Rule Management Recommendation
�� Power User Active chat in the last 30 days AND meaningful Code activity (Equivalent cost ≥ $10.00 OR active days ≥ 3). Keep (Full Value)
�� Chat-Only Active Active chat (≥ 5 conversations in the last 30 days) AND no meaningful Code activity. Keep + Encourage Code adoption
⚡ Code-Only Active Meaningful Code activity (Equivalent cost ≥ $10.00 OR active days ≥ 3) AND minimal chat (< 5 conversations). Keep (Active Developer)
⚠️ Low Engagement Minor activity logged in Drive, but sits below the power/active thresholds in both channels. Review (Encourage training or evaluate)
❌ Truly Inactive Zero active chat sessions AND zero Code tokens logged in Google Drive. Remove (Reclaim license immediately)

��️ The Handoff Safety Guard (Absolute Protection)

To prevent wrongly flagging productive developers who work silently, the system enforces a strict Safety Guard.

Any user with Code equivalent cost ≥ $10.00 OR ≥ 3 active coding days is automatically kept, protected from removal alerts, and classified into an active cohort regardless of their chat metrics.

�� Understanding Equivalent API Costs

The cost figures shown on the dashboard represent the API-equivalent value (what the raw tokens would cost at commercial pay-as-you-go API rates for Sonnet, Opus, and Haiku).

Since Claude licenses are billed on a flat-fee subscription (~$20/user/month), these figures are indicator metrics. A total cost higher than the flat rate proves that the developer is extracting massive, high-leverage value from the seat!

Methodology & Calculation Reference

v2 scoring model — v2.0

Current run thresholds
…

Code Score (0–100)

  • �� Cost rank (30 pts) — last-30-day API-equivalent cost vs team max.
  • �� Active days (30 pts) — distinct active days (with cost or tokens), vs team max.
  • �� Output tokens (20 pts) — actual artifact volume generated, vs team max.
  • �� Project diversity (10 pts) — distinct real projects worked on.
  • �� Cache hit rate (10 pts) — input-side cache reuse (efficient prompting).

v1 used token-volume (40%) which rewarded verbose prompts. v2 swaps in cost-rank + output to reward outcomes.

Ad-hoc Adoption Score (replaces Chat Score)

Number of sessions classified as the ad-hoc CLI bucket (no recognizable project context). v1 derived this from totalSessions − distinctProjects — an algebraic fiction that has no semantic meaning. v2 counts ad-hoc sessions honestly.

Value Score

max(code, chat) + min(code, chat) × 0.2, capped at 100. v1's (code + chat) / 2 + 10 penalized balance (50/50 scored lower than 100/0). v2 rewards the dominant channel with a small hybrid bonus.

Categories

  • �� Onboarding — first observed activity less than 14 days ago.
  • ⭐ Power User — recent activity (≤30d) AND last-30d cost ≥ $5 OR ≥3 active days in last 30.
  • �� Chat-Only Active — recent (≤30d) + ≥5 total sessions but no recent code activity.
  • ⚡ Code-Only Active — has had meaningful code activity but not in the last 30 days.
  • ⚠️ Low Engagement — some lifetime tokens but below power thresholds.
  • ❌ Truly Inactive — zero lifetime tokens captured.

Reclamation confidence (0–100)

Computed from days-since-last-activity + lifetime activity + new-hire status. Replaces v1's hard-coded "99% High / 80% Medium" pills. New hires < 14 days old are always 0 (never flagged for removal).

⚠️ Caveat:

All cost figures are the API-equivalent value of the tokens consumed (what they would cost at commercial pay-as-you-go rates). Actual money spent is the flat $20/user/month subscription. ROI shown is the ratio of the former to the latter, restricted to the last 30 days so monthly comparisons are honest.

Methodology Changelog

  • v2.0 — Period-aware ROI (30d window). Code Score re-weighted (cost+output replaces raw tokens). Chat Score redefined as Ad-hoc Adoption. Tenure-aware categorization (Onboarding). Computed reclamation confidence. Input-side cache hit rate.
  • v1 — Lifetime ROI, token-volume-weighted Code Score, totalSessions − distinctProjects Chat Score, hard-coded confidence pills.
